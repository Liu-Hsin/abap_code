# 界面开发 说明

## 目录结构

- 界面开发/
  - oo alv .abap
  - 策略模式与工厂方法.abap
  - 简单的oo报表.abap
  - MVC模式与单实例模式.abap    

## 文件说明

- `界面开发\oo alv .abap`：面向对象 ALV 报表封装实现，提供通用列表打印与交互查询。
- `界面开发\M策略模式与模式与工厂方法.md`：详解 ABAP OO 中策略模式、工厂方法模式的设计思路、代码实现、适用场景。
- `界面开发\简单的oo报表.abap`：轻量级 OO 报表开发模板，包含数据查询、界面渲染、权限控制基础逻辑。
- `界面开发\MVC模式与单实例模式.abap`：介绍 MVC 模式与单实例模式在 ABAP 界面开发中的应用，提供示例代码与设计建议。
