# 开发辅助类 说明

## 目录结构

- 开发辅助类/
  - (代码下载程序) Y_DOWNLOAD.md
  - abapGit.abap
  - abap_clear.md
  - zbdc.abap

## 文件说明

- `开发辅助类\(代码下载程序) Y_DOWNLOAD.md`：代码下载程序文档，说明如何批量导出 ABAP 开发对象。
- `开发辅助类\abapGit.abap`：与 abapGit 交互的辅助类，实现 Git 操作封装、代码同步。
- `开发辅助类\abap_clear.md`：数据清理脚本说明（如清空临时表、重置测试数据）。
- `开发辅助类\zbdc.abap`：BDC 自动化录入功能，实现事务录入与批量数据载入。
