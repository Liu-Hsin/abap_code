# SAP ABAP 通用代码仓库

## 一、项目概述

本仓库为 SAP ABAP 开发人员提供一套经过项目验证的通用代码资产，覆盖：
- 财务数据批量导入与转换
- 基础工具类（加密、IP 查询、时间戳、格式转换）
- 开发辅助（代码下载、CRUD 清理、BDC）
- Restful 接口开发（HTTP 类、JSON 转数据）
- OO ALV 界面展示与报表

目标：快速交付、减少重复开发、提高团队维护效率。

## 二、仓库结构与文件说明

### 2.1 业务工具类（`业务工具类/`）
- 会计凭证批导.abap：批量生成会计凭证，支持上传、结果回写、异常记录
- 会计科目导入.abap：科目主数据导入与结构校验
- 客户主数据扩充.abap：客户主数据批量更新，支持属性映射与审批规则
- 序时账.abap：生成序时账列表与按期间统计表
- 成本中心导入.abap：成本中心主数据批量导入与公司代码绑定
- 期初资产数据导入.abap：期初资产卡片导入与分配规则
- 物料&财务帐自动打开.abap：自动开启物料账与财务账，支持选择范围
- 配置表汇总维护程序.abap：配置项汇总与导入/导出管理

### 2.2 基础工具类（`基础工具类/`）
- Rsa加密.abap：RSA 密钥生成、加密与解密函数封装
- SAP 实例 IP.abap：获取 SAP 实例 IP、客户端、系统编号等环境信息
- UNIX 时间戳.abap：提供日期/时间 ↔ UNIX 时间戳互转函数
- abap工具类.abap：通用函数库：random、job、SM12 锁处理、文件路径
- 日期转英文简写.abap：格式化日期输出（英文月份简写）
- 系统对象对比.abap：比较两个系统间对象差异（按创建时间/版本）
- 邮件工具类（可带Excel附件）.abap：发送邮件、动态生成 Excel 并附加
- 金额转中文大写.abap：阿拉伯数字转人民币大写
- 金额转大写.abap：数值转大写（含小数）

### 2.3 开发辅助类（`开发辅助类/`）
- (代码下载程序) Y_DOWNLOAD.md：说明如何使用代码下载程序导出文件
- abapGit.abap：abapGit 代码同步和版本发布辅助
- abap_clear.md：清理临时数据、测试数据、无效常量的操作指南
- zbdc.abap：BDC 自动化录入和事务执行逻辑

### 2.4 接口开发（`接口开发/Restful接口/`）
- Class/zcl_int_002.abap：Restful 服务接口具体业务逻辑实现
- Class/zcl_json_to_data.abap：JSON 字符串解析为 ABAP 内表/结构
- Class/zcl_restful.abap：请求/响应封装、异常处理策略
- Class/zif_interface_http.abap：接口定义类型
- 发布服务/README.md：接口发布说明、SICF 激活、权限配置
- 发布服务/rest_application.md：Rest 应用整体配置与部署流程
- 发布服务/restful_method.md：REST 方法编写规范、签名、返回结构
- 发布服务/zcl_int_01.md：示例接口结构与调用流程

### 2.5 界面开发（`界面开发/`）
- oo alv .abap：面向对象设计的 ALV 报表模板，支持筛选、排序、导出、双击事件

## 四、操作指南

1. 打开 SAP GUI，进入 `SE38/SE80`，将需要代码复制入对应程序/类。
2. 业务导入程序请先在测试环境验证关键字段与映射逻辑。
3. 工具类可直接调用 `zcl_abap_tools` 等类方法，无需改动。
4. 接口开发情况下：先完成 Rest 服务注册（SICF），再部署业务类。
5. 生产部署前完成 UT、IT 测试，重点测试财务凭证、期初数据导入的边界数据。

## 六、注意事项

1. 生产环境落地前，务必同步 SAP 基础数据（科目表、客户组等）的具体值；
2. 处理批量财务数据时注意锁机制，避免并发冲突；
3. 涉及敏感数据（如凭证信息）时，推荐做脱敏处理或审计记录；
4. 操作接口时，确保启用 HTTPS，避免明文传输。
