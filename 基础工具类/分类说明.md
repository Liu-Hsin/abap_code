# 基础工具类 说明

## 目录结构

- 基础工具类/
  - Rsa加密.abap
  - SAP 实例 IP.abap
  - UNIX 时间戳.abap
  - abap工具类.abap
  - 日期转英文简写.abap
  - 系统对象对比.abap
  - 邮件工具类（可带Excel附件）.abap
  - 金额转中文大写.abap
  - 金额转大写.abap
  - 计算字符串HMAC.abap

## 文件说明

- `基础工具类\Rsa加密.abap`：RSA 密钥对生成、加密和解密工具。
- `基础工具类\SAP 实例 IP.abap`：获取当前 SAP 系统实例 IP 及端口，供网络监控使用。
- `基础工具类\UNIX 时间戳.abap`：Unix 时间戳 ↔ SAP 日期时间转换函数封装。
- `基础工具类\abap工具类.abap`：通用工具类，包括时间戳、随机字符串、SM12 锁处理、后台作业创建等方法。
- `基础工具类\日期转英文简写.abap`：将 SAP 日期转换为英文简写格式（如 2026-04-02 -> Apr 2）。
- `基础工具类\系统对象对比.abap`：比较两个系统的开发对象差异（如类、程序、表等）。
- `基础工具类\邮件工具类（可带Excel附件）.abap`：发送邮件且支持生成并附加 Excel 文件。
- `基础工具类\金额转中文大写.abap`：人民币金额数字转换为中文大写格式。
- `基础工具类\金额转大写.abap`：数值金额转换为大写字符串，含单位。
- `基础工具类\计算字符串HMAC.abap`：对字符串内容，使用指定密钥和哈希算法，生成 HMAC 签名并返回 Base64 编码字符串。
